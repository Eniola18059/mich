Before you start

Synonym = a word with the same meaning.
Antonym = a word with the opposite meaning.

Dictionary rule: For every question, look up the main word and all four options in your dictionary. You must tick the box before the options unlock.

Questions 1–25 are synonyms. Questions 26–50 are antonyms.
