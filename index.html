Study note: Independent and Dependent Variables

Read this first, then take the quiz.

Independent variable (IV) The thing you change on purpose. Goes on the X-axis (across, horizontal).
Dependent variable (DV) The thing you measure. It changes because of the IV. Goes on the Y-axis (up, vertical).
Quick test: Ask "What did I change?" That is the independent variable. Ask "What did I measure?" That is the dependent variable.

Controlled variables

Controlled variables are everything else that you keep the same so the test is fair. If two things change, you cannot tell which one caused the result. Change only one independent variable at a time.

Worked example 1

Question: Does the size of a paper airplane's wings change how far it flies?

Part of the experimentAnswer
Independent variable (changed)Wing size
Dependent variable (measured)Distance the plane flies
Controlled variables (kept the same)Type of paper, the thrower, the throwing strength, the room
X-axisWing size (cm)
Y-axisDistance flown (m)

Part of the experimentAnswer
Independent variableHours studied

How it looks on a graph

Remember

  • Independent = I change it = X-axis (goes across).
  • Dependent = Data I measure = Y-axis (goes up).
  • Always label both axes with units.
